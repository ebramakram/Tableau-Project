# 👥 HR Dashboard Project | Tableau

An end-to-end **HR Dashboard project built in Tableau**, focusing on clean design, usability, and actionable HR insights.  
The project encompasses the entire dashboard lifecycle, from data preparation to UI enhancement.

---

## 📌 Project Overview
- Tool: Tableau  
- Domain: HR Analytics  
- Dashboards: Summary & Detailed  
- Focus: Data storytelling, UX, best practices  

---

## 🗂 Project Workflow

**- Color Schema**  
Defined a consistent color palette for clarity and visual hierarchy.

**- Project Steps**  
Planned KPIs, scope, and dashboard structure.

**- Build Data Source**  
Prepared and validated HR data in Tableau.

**- Build Charts**  
Created core HR visuals (headcount, attrition, demographics).

**- Plan Summary Dashboard**  
Designed layout for executive-level insights.

**- Build Summary Dashboard**  
Implemented KPIs, charts, and filters.

**— Fine-Tuning Summary Dashboard**  
Improved formatting, tooltips, and usability.

**— Build Additional Charts**  
Added supporting visuals for deeper analysis.

**— Plan Detailed Dashboard**  
Designed drill-down views and user flow.

**- Build Detailed Dashboard**  
Built detailed dashboards with filters and actions.

**- Summary**  
Final validation and review of insights.
